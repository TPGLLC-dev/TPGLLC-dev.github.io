# The Pulse Family of Apps — website

Served by GitHub Pages at https://pulsefamily.app/ — the family page plus one
page per app (`magipulse/`, `seapulse/`, `studipulse/`, `magicalpulse/`).

- Every claim on a page describes the app as it ships today; each page's header
  comment says what was checked and when. "Coming soon" stays until the App
  Store listing is live.
- Privacy, terms and support links still point at each app's existing legal site
  (`MagiPulse-legal`, `SeaPulse`, `StudiPulse-legal`, `MagiCalPulse-legal`).
  Shipped builds and App Store Connect use those addresses, so they move here
  only with each app's next build, and the old sites then forward. Never delete
  the old legal repos.
- Videos are 720 px web copies of the finished promo videos (~3 MB each).
- No cookies, no analytics, no third-party requests (the display font is
  self-hosted, SIL OFL — see `assets/fonts/OFL.txt`).
- No Disney, Universal or SeaWorld logos, photos or fonts.
